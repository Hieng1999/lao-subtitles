Please read before downloading

These subtitles are translated by a local machine-translation model. No human has reviewed these files. "Subtitles" files were translated from real English subtitle files by a newer version of the model (NLLB-200 1.3B with the LoRA adapter S3X), with no cloud AI step and no find-and-replace rule tables. An earlier automatic review step, used only for the older "Translated screenplay" files, also sent lines to a cloud AI service (Google Gemini) and applied some of its edits to the Lao; those files are being replaced by real subtitle files as they arrive, and this step is not used for "Subtitles" files at all. The model was fine-tuned mostly on machine-translated text, including earlier output of this project and corrections written by Google Gemini; only a small share of its training data was translated by people. Errors, stiff or unnatural phrasing, and occasional mistranslations are expected -- this is machine output, not a professional or community human translation.

This catalog has two kinds of file. "Subtitles" are timed to a specific film's real dialogue and are machine-translated, not reviewed by a person. "Translated screenplays" are a screenplay, sometimes only an excerpt, translated to Lao with synthetic, evenly-spaced timing (not synced to any actual film) -- useful to read, not to play alongside a video.

If you find a bad line, please use the "🚩 Report a bad line" link on that movie's card to open a GitHub issue.

🏆 How We Verify Quality Machine-Checked

The numbers below are about the older "Translated screenplay" files only. Each of those was re-translated fresh and compared against the published line; the 6,183 corrections counted below were applied only if they passed both a semantic-equivalence check (translated back to English and compared to the original) and a set of filters for known failure patterns — never either one alone. No human reviewed any of it.

"Subtitles" files (S3X) are checked differently: the model's loaded weights are verified against the adapter file on disk, every line's timing is checked against its English source file, every line is confirmed non-empty, credit and ad lines are removed, and the same automatic defect-pattern checks are run against the translated text. No quality score is published for these files -- no native Lao reader has reviewed them yet.
