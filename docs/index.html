Free, high-quality Lao subtitle files (.srt) for 285 legendary feature films

Please read before downloading

These subtitles are translated by a local machine-translation model. No human has reviewed these files. Errors, stiff or unnatural phrasing, and occasional mistranslations are expected -- this is machine output, not a professional or community human translation.

This catalog has two kinds of file. "Subtitles" are timed to a specific film's real dialogue and are machine-translated, not reviewed by a person. "Translated screenplays" are a full script translated to Lao with synthetic, evenly-spaced timing (not synced to any actual film) -- useful to read, not to play alongside a video.

If you find a bad line, please use the "🚩 Report a bad line" link on that movie's card to open a GitHub issue.

Major subtitle websites (OpenSubtitles, Subscene, Addic7ed) do not support Lao as a language. There is no category to search or upload to, leaving Lao speakers without subtitles for global cinema. This open-source repository bridges that gap using modern local neural translation fine-tuned on an NVIDIA GeForce RTX 5090.

🏆 How We Verify Quality Independently Re-Checked

Every movie is re-translated fresh and compared against the published line. A fix is only applied if it passes both an independent semantic-equivalence check (translated back to English and compared to the original) and a set of filters for known failure patterns — never either one alone.
