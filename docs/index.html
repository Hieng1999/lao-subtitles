This open-source repository bridges that gap using modern local neural translation fine-tuned on an NVIDIA GeForce RTX 5090.

📺 How to Use with Your Movies

  1. Click Download .srt for the movie you want to watch.
  2. Place the .srt file in the same folder as your movie video file (e.g. Coco.2017.mp4 and Coco.2017.srt).
  3. Open the video in VLC, MPV, Plex, IINA, or PotPlayer — the Lao subtitles will automatically appear!
  4. Timing adjustment: If your movie video release has extra opening studio logos, nudge the subtitle sync in VLC by pressing G (earlier) or H (later).

❤️ About This Project

This started with a simple wish: to help someone I love enjoy movies in the language they're most comfortable in. Lao subtitles for major films basically don't exist online — so I built a translation pipeline and started making them, and I'm sharing the results here free for anyone to use. If they help even one more family enjoy a movie together, it's worth it.
