Lao Movie Subtitles

ຄຳບັນຍາຍພາສາລາວ — free Lao subtitles for the movies you love

Major subtitle sites don't support Lao at all — there's no Lao category to search or upload to. So these films had no Lao subtitles anywhere. This project fills that gap so Lao speakers can enjoy movies in their own language. Everything here is free to download.

These subtitles are AI-assisted translations (reviewed by hand), not professional human work. Corrections from native Lao speakers are very welcome — open an issue or pull request on GitHub.

How to use

Download the .srt, put it next to your movie file (or open it in VLC / MPV / Plex). If the timing is off, your video is a different release — nudge the subtitle delay in your player.
