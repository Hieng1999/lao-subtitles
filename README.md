### Please read before downloading

These subtitles are translated by a local machine-translation model. **No human has reviewed these files.** "Subtitles" files were translated from real English subtitle files by a newer version of the model (NLLB-200 1.3B with the LoRA adapter S3X), with no cloud AI step and no find-and-replace rule tables. An earlier automatic review step, used only for the older "Translated screenplay" files, also sent lines to a cloud AI service (Google Gemini) and applied some of its edits to the Lao; those files are being replaced by real subtitle files as they arrive, and this step is not used for "Subtitles" files at all. Errors, stiff or unnatural phrasing, and occasional mistranslations are expected -- this is machine output, not a professional or community human translation. If you find a bad line, please open an issue: see **Report a bad line** below.

This catalog has two kinds of file. "Subtitles" are timed to a specific film's real dialogue and are machine-translated, not reviewed by a person. "Translated screenplays" are a screenplay, sometimes only an excerpt, translated to Lao with synthetic, evenly-spaced timing (not synced to any actual film) -- useful to read, not to play alongside a video.

Machine-translated Lao .srt files for **797 films** -- **1,020,269 dialogue cues** in all.

🌐 **Browse, search & download directly at the live website → [hieng1999.github.io/lao-subtitles](https://hieng1999.github.io/lao-subtitles/)**

Lao subtitles for most films are hard or impossible to find on the major subtitle sites, which is why this project exists. It does not search those sites, so it makes no claim about whether any particular film has Lao subtitles somewhere else. Everything here is **free to download**.

## 🏆 How We Verify Quality

The numbers below are about the older "Translated screenplay" files only. Each of those was re-translated fresh and compared against the published line, and a correction was written only when it passed both a set of filters for known failure patterns and a semantic-equivalence check -- never either one alone. For that second check the candidate Lao line is translated back into English by a separate reverse-direction model, and a local LLM running on this machine is asked only whether the two English sentences mean the same thing; it is never shown any Lao. No human reviewed any of it.

"Subtitles" files (S3X) are checked differently: the model's loaded weights are verified against the adapter file on disk, every line's timing is checked against its English source file, every line is confirmed non-empty, credit and ad lines are removed, and the same automatic defect-pattern checks are run against the translated text. They are not re-translated a second time and compared, so none of the numbers below cover them. No quality score is published for these files -- no native Lao reader has reviewed them yet.

Every row of the table below is counted over one set: the **187 "Translated screenplay" films still published here** (187 of this catalog's 797 films), re-summed for this build from the run's own per-film state file, `lao_nlp/data/metadata_and_state/srt_verification_state.json`, in the translator repository. The run itself covered 287 films; 100 of those are no longer published and are not counted anywhere below.

**How a correction gets approved -- the "double lock":** a candidate replacement only ever got written to a published `.srt` file if it passed **both** of these, independently:

1. **Deterministic Lao-text filters** -- reject anything matching a known decoder failure mode we found and catalogued by hand: a garbled placeholder token, a real word ("cat", "interfere") standing in for a slang term it shouldn't, an immediately-repeated stutter, or English words left untranslated inside the Lao line.
2. **English-only back-translation judge** -- the candidate Lao line is translated *back* into English with a separate reverse-direction model, and a local LLM judge, running on this machine, is asked only "do these two English sentences mean the same thing?" -- it never reads Lao, so it can't be fooled by fluent-looking-but-wrong Lao text.

> **We're not claiming this is perfect.** Some known failure patterns -- like a specific word the model occasionally substitutes for slang or profanity it doesn't have a good translation for -- are hard to fully eliminate through re-translation alone, and a small number of these remain in the catalog even after this process (see **Contributing & Corrections** below for how to report one). We'd rather tell you that honestly than publish a big round number that doesn't hold up.

## 🧠 How These Subtitles Are Produced

Translation runs on a local model (NLLB-200 1.3B with a LoRA adapter) on an **NVIDIA GeForce RTX 5090**. The model was fine-tuned mostly on machine-translated text, including earlier output of this project and corrections written by Google Gemini; only a small share of its training data was translated by people. "Subtitles" files were translated from real English subtitle files by a newer version of the model (NLLB-200 1.3B with the LoRA adapter S3X), with no cloud AI step and no find-and-replace rule tables. An earlier automatic review step, used only for the older "Translated screenplay" files, also sent lines to a cloud AI service (Google Gemini) and applied some of its edits to the Lao; those files are being replaced by real subtitle files as they arrive, and this step is not used for "Subtitles" files at all. No person has reviewed these files.

1. **"Subtitles" files (610 of the 797 films here)** -- a real English subtitle file for that film is translated line by line by the S3X adapter, and the Lao text is written straight out: no cloud AI step, no find-and-replace rule tables, and no second pass that re-translates the line and compares it.
2. **"Translated screenplay" files (187 films)** -- older Generation 4 output, made from a screenplay rather than a subtitle file, and put through the two automatic checks described in **How We Verify Quality** above. The corrections that run found were never used to retrain the model: that plan was dropped before training started. These files are being replaced by "Subtitles" files as real subtitle sources arrive.
3. **Automatic checks on every file** -- each line is confirmed non-empty, and credit and advertising lines carried in from the English file are removed.
4. **Timing** -- "Subtitles" files keep the timing of the English subtitle file they were translated from. That file may have been timed for a different release of the film, so lines can run early or late -- use your player's subtitle-delay keys to shift them. "Translated screenplay" files have synthetic, evenly-spaced timing and will not line up with a video at all. Nothing here is aligned to a film's audio: no step of this project reads or listens to the video.

## 📺 How to Use

These steps are for **"Subtitles"** files. A **"Translated screenplay"** file is for reading: its timing is synthetic, so it will not line up with a video.

1. **Download**: on the [website](https://hieng1999.github.io/lao-subtitles/), click a film's **🇱🇦 Lao SRT** button (on a "Translated screenplay" card that button reads **🇱🇦 Lao script (SRT)**), or **🇺🇸/🇱🇦 Bilingual** for the English-and-Lao file. In this README, use the links in the tables above.
2. **Rename**: rename the `.srt` file so its name matches your video file exactly:
   ```
   2001.A.Space.Odyssey.1968.mkv
   2001.A.Space.Odyssey.1968.srt
   ```
3. **Play**: open the video in **VLC**, **MPV**, **Plex**, **IINA**, or **PotPlayer** -- the Lao subtitles will appear.
4. **Timing**: "Subtitles" files keep the timing of the English subtitle file they were translated from. That file may have been timed for a different release of the film, so lines can run early or late -- use your player's subtitle-delay keys to shift them. "Translated screenplay" files have synthetic, evenly-spaced timing and will not line up with a video at all. In VLC that is `G` (earlier) and `H` (later).
